# Code of Conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. By participating in issues, pull requests, discussions or any other project
space, you agree to uphold it.

In short: be respectful and constructive, assume good intent, and welcome people of every background
and experience level. Harassment, discrimination, personal attacks, and publishing others' private
information are not tolerated.

## Reporting

If you experience or witness unacceptable behavior, report it privately to the project maintainers,
using the contact details on their GitHub profiles, or GitHub's **Report content** option on the
comment, issue or pull request. Please don't raise it in a public thread. Reports are handled
confidentially.

Security vulnerabilities are not conduct issues; report them as described in
[`SECURITY.md`](SECURITY.md).

## Enforcement

Maintainers follow the Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines):
correction, warning, temporary ban or permanent ban, depending on the severity and pattern of
behavior.
